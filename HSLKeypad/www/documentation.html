HSL Keypad

Control4 agent · version 0.0.6 · OS 3.4.x and X4

HSL Keypad lets the HSL Toolbar Mac app show 12-button keypad pages for this project. The Mac assigns the buttons; this agent publishes everything that can be assigned, runs the commands, and reports state back so the buttons stay lit correctly. It works on the local network, or over a VPN to it.

What the Mac can put on a button

LightsToggle, on, off, or a set level · hold to dim · right-click for a level sliderOn/off and level

WatchSelect a room's video source, or toggle it (selected → room off)Whether the room is watching it

Lights, fans, rooms, scenes, macros and sources are found automatically and republished when the project changes (devices added, removed, renamed or moved).

Setup

  1. Driver → Add or Update Driver or Agent → choose HSLKeypad.c4z.
  2. Agents → add HSL Keypad. One per project.
  3. Optional: set Site Name (how the Mac labels this site) and Port (default 8751).
  4. On the Mac: HSL Toolbar → Settings → Control4 → +. Enter this controller's IP address, the port, and the Pairing Code from this agent's properties, then click Pair & Connect.
  5. On the Mac: open the H in the menu bar → Smart Home → Edit to assign buttons.

Updates

The agent checks github.com/encondata/hsl_Keypad/releases and shows the result in Update Status; paired Macs show it too, with a download link. Control4 only installs updates automatically for drivers hosted in its own driver database, so install a new version yourself: download HSLKeypad.c4z, then Driver → Add or Update Driver or Agent. Its higher build number replaces the installed agent.

Troubleshooting

  • The Mac can't connect. Check the IP and port, that the Mac is on this network (or its VPN), and that Status says “Listening”.
  • “Wrong pairing code” or “Too many”. Use the current Pairing Code; after five wrong tries, wait a minute.
  • Scenes, macros or Watch/Listen sources are missing. Run Log Project Info with Debug Mode on and send the Lua output to HackSpaceLabs. This version finds them automatically where the controller allows it.
