HSL Keypad agent

HackSpaceLabs · for Control4 OS 3.4 and X4

Lets the HSL Toolbar app on a Mac show a 12-button keypad for this project's lights and fans. The Mac assigns the buttons; this agent publishes what can be assigned, runs commands, and reports state. It works on the local network (or over a VPN to it).

Setup

  1. Add the agent (Agents → Add, or Driver → Add or Update Driver or Agent). One per project.
  2. Optionally set Site Name (shown in the Mac app) and Port (default 8751).
  3. On the Mac: HSL Toolbar → Settings → Control4 → add the controller's IP address and port, enter the Pairing Code shown in this agent's properties, and click Pair & Connect.

Properties

Site NameName the Mac app shows for this site.
PortTCP port the Mac app connects to.
Pairing Code6-digit code for pairing a Mac. Five wrong attempts lock pairing for a minute.
Paired MacsMacs that can connect.
StatusListening state, connected Macs, and devices found.
Debug ModeLogs activity to the Lua output window.

Actions

New Pairing CodeReplaces the code (paired Macs stay paired).
Unpair All MacsDisconnects and forgets every Mac.
Refresh DevicesRe-reads lights and fans now (it also happens automatically when the project changes).
Log Project InfoPrints what this controller exposes to the Lua output window, for troubleshooting.

Current version

Lights (on, off, toggle, level, press-and-hold dimming) and fans (on, off, toggle, speed). Advanced Lighting scenes and macros are planned.
