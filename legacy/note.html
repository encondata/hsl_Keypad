Legacy package for OS 3.3.x. This is HSLKeypad-legacy.c4z, a separate agent from the standard HSLKeypad.c4z (OS 3.4.x and X4). Install only one of them in a project — both listen on the same port. Updates for this agent are always the HSLKeypad-legacy.c4z file of a release. On OS 3.3, scenes, macros, Watch / Listen sources and fan speed names depend on requests that are confirmed on X4 only; if any are missing, run Log Project Info.
